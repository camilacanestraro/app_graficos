# Dashboard Interativo e-Commerce (Dash & Plotly)

Aplicação web interativa desenvolvida com Python, Dash e Plotly para exploração estatística de dados de e-commerce.

## 📊 Funcionalidades
- **Filtros Interativos:** Seleção por gênero e controle deslizante de faixa de preço com atualização dinâmica dos gráficos.
- **Gráficos Variados:**
  - Histograma (Distribuição de preços)
  - Gráfico de Pizza (Proporção por gênero)
  - Gráfico de Bolhas (Relação Preço x Desconto x Quantidade Vendida)
  - Gráfico de Linhas (Tendência de vendas)
  - Gráfico 3D (Preço x Nota x Desconto)
  - Gráfico de Barras (Top 10 marcas mais vendidas)
